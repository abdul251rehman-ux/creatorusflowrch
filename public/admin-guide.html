Tab 1 — Content

This is the most important tab. Fill this out first. Fields marked * are required — the post will not save without them.

Title Required

The main headline of your blog post. Keep it clear and descriptive.
Example: "How to Grow on Instagram in 2025"

Slug Required

The URL of your post. Auto-fills from your title — you don't need to type it. It will look like:
creatorflowus.com/blog/how-to-grow-on-instagram

Excerpt Optional

A short 1–2 sentence summary. Shown on the blog listing page under the title. Also used in Google search results if you don't fill in the SEO description.

Content (Markdown) Required

The full article. Written in Markdown format (see cheat sheet below). Click the Preview button in the top-right to see how it looks formatted.

Cover Image — Upload tab Optional

Click the dashed area or the Upload Image button to pick a file from your computer. Accepted formats: PNG, JPG, WebP. Max size: 10 MB. The image is automatically saved to the website's storage.

Cover Image — URL tab Optional

If you already have an image hosted somewhere (Unsplash, Google Drive public link, etc.), switch to the URL tab, paste the link, wait for the preview to show "Ready", then click Use Image.

Cover Image Alt Text Optional

A short description of the image. Used by screen readers and helps Google understand what the image is.
Example: "Person scrolling Instagram on a phone"

Open Graph Image Optional

A separate image shown when someone shares your post on Twitter, Facebook, or LinkedIn. Recommended size: 1200 × 630 pixels. If left blank, the cover image is used instead.

📐

Best image size for Cover Images

Use a landscape image at least 1200px wide. The cover displays at a 16:9 ratio on the post page and 3:2 on the listing grid. JPG or WebP format gives the best quality at smallest file size.

Tab 3 — Details

Set the status, category, author, tags, and extra options for the post.

Status

Choose where this post is in its lifecycle. This controls whether it's visible to the public.

🟡 Draft

Saved but not visible to the public. Use this while writing. The default for new posts.

🟣 Review

Ready to be checked before publishing. Still not visible to the public.

🔵 Scheduled

Set a future date and time. The post goes live automatically at that moment.

🟢 Published

Live on the website right now. Visible to everyone at creatorflowus.com/blog.

⚫ Archived

Hidden from the public blog listing. The post still exists but is no longer visible. Use this instead of deleting.

Category Optional

Choose from your pre-set categories (e.g. Social Media, Content Creation). Shows as a coloured badge on the post and listing page. Select from the dropdown.

Author Optional

Select who wrote the post from the dropdown. Their name, photo, and bio will appear on the published post automatically.

Tags Optional

Keywords that describe the post. Type them separated by commas.
Example: instagram, growth, reels, 2025
They appear as coloured chips at the bottom of the post.

Language Optional

The language the post is written in. Defaults to English. Change only if writing in another language.

Series Name + Part # Optional

If this post is part of a series, enter the series name and which part number it is.
Example: Series — "TikTok Masterclass", Part — 2

Scheduled Publish Date

Only appears when Status is set to Scheduled. Pick the exact date and time for the post to go live.

Toggles

⭐ Featured Post

Highlighted with a "★ Featured" badge on the blog listing and post page.

🛡 Premium Content

Gated — only visible to subscribers. Use for exclusive content.

💬 Allow Comments

Lets readers leave comments on this post. On by default.

SEO Title Optional

What appears as the blue clickable link in Google. Keep it under 60 characters. The counter turns green when you're at the ideal length.
Example: "Grow on Instagram in 2025 | CreatorFlowUS"

Meta Description Optional

The grey text shown below the title in Google results. Keep it under 160 characters. Should describe what the reader will learn.
Example: "Learn 10 proven strategies to grow your Instagram account in 2025 — from Reels to hashtags."

Canonical URL Optional

Only needed if this post was originally published somewhere else (e.g. your Medium or LinkedIn). Paste the original URL here so Google knows where the content came from. Leave blank for original posts.

Hide from Search Engines Toggle

Turn this ON to tell Google not to index this post. Use for test posts, internal drafts that accidentally got published, or pages you don't want in search results.

🔍

Google Preview — Live as you type

At the bottom of the SEO tab, you'll see a live Google Preview card that shows exactly how your post will appear in search results. It updates as you type the SEO Title and Meta Description.

Saving & Publishing

Once all tabs are filled in, save the post and control when it goes live.

The Footer Bar

At the bottom of the form you always see three things:

Published
Cancel
✓ Save Post
Status pill (left)

Shows the current status in colour. You set this in the Details tab. When status is Published, this pill is green — that means the post will go live the moment you click Save.

Cancel button

Closes the form without saving anything. Any unsaved changes will be lost.

Save Post / Update Post button

Saves everything. The button shows Save Post for new posts and Update Post when editing an existing one. You'll see a green toast notification at the top of the screen when it succeeds.

Required fields

If you click Save without filling in Title, Slug, or Content, a red error message appears at the top of the form. Fill in the missing fields and try again.

Quick Publish Checklist

✅

Before clicking Save Post, check:

☐ Title is filled in
☐ Content is written and previewed
☐ Excerpt added (helps SEO and listing page)
☐ Cover Image uploaded or URL set
☐ Category selected
☐ Author selected
☐ Status set to Published (or Scheduled with a date)
☐ SEO Description written (60–160 characters)

🌐

When does the post appear on the website?

Within 60 seconds of saving with status Published, the post appears on creatorflowus.com/blog and at its own URL creatorflowus.com/blog/[slug].

Editing an Existing Post

From the dashboard, click the ✏️ pencil icon on any post. The same form opens with all existing data pre-filled. Make your changes across any tab, then click Update Post. Changes appear on the live site within 60 seconds.

Deleting a Post

Click the 🗑 trash icon on any post in the dashboard list. A confirmation appears — click Delete to confirm. This is permanent and cannot be undone. If you just want to hide a post temporarily, use Archived status instead of deleting.
