# creatorusflow-next

Next.js migration of the CREATORUSFLOW static site.

Quick start (Windows PowerShell):

1. Change into the project folder:

```powershell
cd "c:\Users\Administrator\Desktop\SOCIAL MEDIA WEB\creatorusflow-next"
```

2. Install dependencies:

```powershell
npm install
```

3. Run development server:

```powershell
npm run dev
```

Open http://localhost:3000 in your browser.

Notes:
- Replace `/public/placeholder-hero.jpg` with a real hero image.
- The contact API at `/api/contact` is a placeholder; integrate with your email/DB service.
- This scaffold uses the Pages Router (`/pages`).
